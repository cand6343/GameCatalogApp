# GameVault — Интерактивный каталог компьютерных игр

## Описание проекта
Веб-приложение для ведения и управления каталогом компьютерных игр. Проект состоит из адаптивного клиентского интерфейса (Frontend) и серверной части (Backend) на базе REST API. Хранение данных осуществляется в оперативной памяти приложения (In-Memory коллекция) без использования сторонних баз данных.

## Используемые технологии
* **Backend:** C#, .NET 8, ASP.NET Core Minimal Web API.
  * Возможности языка C#: `record`, `LINQ`, `pattern matching`, `switch expression`, `async/await`.
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (ES6+, Fetch API).
* **Инструменты разработки:** Visual Studio Code (Linux), Git.
